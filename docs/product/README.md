# Follei product source archive

This directory versions the product inputs used for the onboarding and knowledge-ingestion rebuild.

- `Follei_Product_Design.pdf` — original product/design baseline.
- `Follei_Autonomous_Business_Workforce_Platform.pdf` — platform architecture brief.
- `follei-onboarding-build-prompt.md` — onboarding engineering brief.
- `follei-project-context.md` — broader project context supplied with the brief.
- `follei-knowledge-ingestion-storage-retrieval-spec.md` — canonical storage and retrieval companion.

The Git branch `old-follei` points at the repository state immediately before this rebuild. These files are reference material; executable contracts live in the application schemas, taxonomy registry, and Alembic migrations.
